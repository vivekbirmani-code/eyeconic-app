Excel Format
Prepare your Excel sheet with the following columns (headers are case-insensitive):

Column Header	Description	Example
SUBJECT	(Required) Subject name	Pathology
TOPIC	(Optional) Topic name	Genetics
QUESTION	(Required) Question text	What is ...?
Q_IMAGE	(Optional) Image URL (Direct or Google Drive)	https://drive.google.com/...
OPTION1	(Required) First option	Option A
OPTION2	(Required) Second option	Option B
OPTION3	(Optional) Third option	Option C
OPTION4	(Optional) Fourth option	Option D
O_IMAGE_1	(Optional) Image for Option 1	https://...
O_IMAGE_2	(Optional) Image for Option 2	https://...
O_IMAGE_3	(Optional) Image for Option 3	https://...
O_IMAGE_4	(Optional) Image for Option 4	https://...
CORRECT	(Required) Correct Answer (1-4 or A-D)	1 or A
EXPLANATION	(Optional) Explanation text	Because...
EX_IMAGE	(Optional) Image for Explanation	https://...
MARKS	(Optional) Marks	4
